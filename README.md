# EEz Study Portal

A student-built study portal for first-year Electrical Engineering students at Universiti Malaya.

**Live demo:** [eez-study-portal.pages.dev](https://eez-study-portal.pages.dev/)

## What it includes

- Semester 1 and Semester 2 course resource libraries
- Study hub with planning and focus tools
- Search across subjects and learning resources
- AI study prompt library
- Links to the associated learning materials

## Tech stack

- Next.js 16 and React 19
- TypeScript
- Motion for interface animation
- CSS and Tailwind/PostCSS tooling

## Run locally

Requires Node.js 22.13 or later and npm.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Use `npm run build` for a production build.

## Notes

The portal links to course files hosted separately in Google Drive; those documents are not bundled in this repository. Personal portrait imagery and local hosting metadata are omitted from this portfolio copy. The live demo remains the best place to view the complete deployed experience.
